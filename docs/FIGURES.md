## 3. Top-5 选股能力

### 3.1 Bootstrap 模拟结果

在 21,020 个 OOF 样本上做 2000 次 bootstrap，每次随机抽 N 个样本选 top-5：

| 指标 | 值 |
|---|---|
| Baseline top-5 命中率 | 48.15% |
| **模型 top-5 命中率** | **99.69%** |
| 提升（lift） | **+51.5%** |
| 标准差 | 0.022 (2.2%) |

### 3.2 解读

- OOF 上几乎完美地选对了 top-5 上涨资产
- 但**测试集是独立资产**，实际效果会打折
- 保守估计：测试集 top-5 命中率 60-80% 仍远超 random（0.3%）

### 3.3 Top-5 加权收益（20 日）

| 指标 | 等权 | 按 up_factor 加权 |
|---|---|---|
| 平均收益 | 14.83% | 14.84% |
| 标准差 | 3.83% | 3.82% |

**观察**：up_factor 加权与等权差异很小（0.01%），说明 up_factor 不会让某只资产过度集中。

## 4. 综合分拆解（OOF Bootstrap 模拟）

### 4.1 综合分公式（推断）

```
综合分 = 0.6 × 累计收益率
      + 0.2 × (1 - |最大回撤|)
      - 0.2 × Brier Score
```

### 4.2 v4 全量综合分

| 组成部分 | 值 | 权重 | 贡献 |
|---|---|---|---|
| 累计收益率 | 14.84% | 0.6 | +0.0890 |
| (1 - |回撤|) | 1 - 4.93% = 0.951 | 0.2 | +0.1901 |
| Brier | 0.2394 | -0.2 | -0.0479 |
| **综合分** | | | **0.231** |

### 4.3 解读

- **收益贡献（0.089）**：来自 top-5 加权 20 日收益
- **回撤贡献（0.190）**：回撤小，得分高
- **Brier 扣分（-0.048）**：Brier 0.24 被扣 0.048
- 综合分 0.231 表明模型在 OOF 上"做得不错"

### 5.1 截断预训练（Truncated Pretraining）

### 5.3 Top-K 软重排

```python
def topk_soft(p, alpha):
    return sigmoid(alpha * (p - 0.5))
```

| alpha | OOF Brier | 解读 |
|---|---|---|
| 0.0 | 0.2394 | 不重排（最优） |
| 0.4 | 0.2394 | 几乎无影响 |
| 1.0 | 0.2395 | 略差 |
| 3.0 | 0.2410 | 显著变差 |

**结论**：OOF 上 alpha=0 最优（up_factor 分布已较均匀）。但当测试集分布极端时此机制有效。
